# Results

Outputs from the Phase II experiments. All files are produced by the notebooks
and can be regenerated by re-running them.

Every model was evaluated on the same held-out test set of 50,736 records,
taken from the stratified 80/20 split in `src/evaluation.py`
(`random_state=42`), so all files here are directly comparable.

## Metrics

| File | Produced by | Contents |
|---|---|---|
| `conventional_test_metrics.csv` | Notebook 06 | Held-out test metrics for the nine conventional model variants |
| `lcs_test_metrics.csv` | Notebook 08 | Held-out test metrics for the three eLCS configurations |
| `conventional_cv_scores.csv` | Notebook 06 | Per-fold scores from stratified 10-fold cross-validation, one row per model per fold |
| `imbalance_strategy_comparison.csv` | Notebook 06 | Balanced accuracy by imbalance strategy: class weighting, undersampling, SMOTENC |

The two metrics files share a common format and are combined into the full
Task 6 comparison by `load_all_metrics()` in `src/evaluation.py`.

## Statistical tests

| File | Produced by | Contents |
|---|---|---|
| `conventional_wilcoxon.csv` | Notebook 06 | All-pairs Wilcoxon signed-rank tests on fold scores. Retained to show why this procedure cannot detect a difference in this design: with 10 folds the smallest possible p-value is 0.00195, and Holm correction across 36 pairs raises it above 0.05 |
| `conventional_wilcoxon_vs_control.csv` | Notebook 06 | Wilcoxon tests against the best model as control, which is the post-hoc procedure the analysis relies on |
| `conventional_mcnemar.csv` | Notebook 06 | McNemar's test between the conventional models |
| `full_comparison_mcnemar.csv` | Notebook 08 | McNemar's test across all twelve models, 66 pairs, Holm corrected |

## Rules

| File | Produced by | Contents |
|---|---|---|
| `improved_elcs_rules.csv` | Notebook 08 | Final rule population of the improved eLCS: 1,821 classifiers with their conditions, predicted class, accuracy, numerosity and match counts. Analysed in notebook 09 |

## Predictions

`predictions/` holds the test-set predictions of every model as NumPy arrays,
plus `y_test.npy` with the true labels.

These exist so that models trained in different notebooks, and in different
Python environments, can be compared without being refitted. The LCS models
run under Python 3.9 with `scikit-eLCS`, while the conventional models were
run separately; McNemar's test needs both sets of predictions on the same
records, and saving them avoids repeating the slow eLCS runs.

Load them with `load_predictions()` in `src/evaluation.py`, which also checks
that every array matches the length of `y_test.npy` and refuses to load if not,
since arrays of different lengths would mean the models were not evaluated on
the same split.

File names follow the model names, with spaces replaced by underscores and
brackets removed: `Random_Forest_B.npy` is Random Forest under imbalance
strategy B (undersampled training data).
